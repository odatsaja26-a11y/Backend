# GoFun AI

The AI team is responsible for building the AI-powered trip planning experience.

## Responsibilities
- Understand User Requirements
- Ask Follow-up Questions
- Generate Personalized Trip Plans
- Recommend Places and Activities
- Consider Budget, Duration, and Group Size
- Integrate with Backend Tools
- Return Structured Responses
- Support Arabic and English

## Important Rules
- Never invent prices.
- Retrieve price data through backend tools.
- Use backend calculations for trip costs.
- Suggest alternatives when the budget is insufficient.
- Keep AI responses aligned with available data.
