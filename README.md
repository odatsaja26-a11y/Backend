# GoFun

GoFun is an AI-powered trip planning platform that helps users create personalized itineraries based on their budget, location, interests, transportation, and group size.

## Target Audience
- Primary: 18–35 years old
- Secondary: 36–50 years old

## Initial Market
Jordan, with a long-term goal of global expansion.

## Main Features
- AI-powered trip planning
- Quick Trip Setup
- Personalized trip recommendations
- Budget and cost estimation
- Route visualization
- Trip saving and management
- Feedback and actual expense reporting
- Arabic and English support

## Project Structure
- `frontend/` — React web application
- `backend/` — .NET API and business logic
- `ai/` — AI trip planning
- `docs/` — Project documentation
- `tests/` — QA and testing
- `infrastructure/` — DevOps and deployment

## Technology Stack
- React
- .NET / ASP.NET Core
- PostgreSQL
- AI Integration

## Development Workflow
All changes should be developed on feature branches and submitted through Pull Requests.

The `main` branch should be protected against unreviewed changes.
